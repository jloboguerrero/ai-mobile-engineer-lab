# Styling & design system — Unistyles 3

## Layers (`src/ui`)

tokens (generated) → theme (brand × mode) → primitives (Box, Text, Pressable) → components
(Button, Card, Sheet, Badge, ListItem…) → form (Form* wrappers) → layout (Screen, Section).
`src/ui/index.ts` is the only import path: `import { Button, Card } from '@/ui';`

## Tokens

- Generated by `scripts/tokens.ts` from the DS CSS (`shr-tokens.css`; Staffology: `staffology-tokens.css`)
  into `src/ui/tokens/generated/`. **Never hand-edit** — change the CSS source and regenerate.
- Primitive tokens (raw palette) are **not** used by components. Only semantic tokens:
  `theme.colors.surface`, `theme.colors.textMuted`, `theme.space(4)`, `theme.radius.md`, `theme.typography.body`.

## Writing styles

```tsx
import { StyleSheet } from 'react-native-unistyles';

export function TimeOffCard({ summary }: TimeOffCardProps) {
  return <View style={styles.card}>…</View>;
}

const styles = StyleSheet.create((theme) => ({
  card: {
    backgroundColor: theme.colors.surface,
    borderRadius: theme.radius.md,
    gap: theme.space(2),
    padding: theme.space(4),
  },
}));
```

- `StyleSheet.create` at the bottom of the file; keys sorted.
- No hex colors, no magic numbers for spacing/font sizes. (`0`, `1` for hairlines, `100%` are fine.)
- Variants via Unistyles `variants`, not ternaries scattered in JSX.
- No inline `style={{…}}` except truly dynamic values (animated, measured).
- Dark mode: only if product confirms (open question); theme supports it, app may force light.
- Catalog: every new `src/ui` component gets an entry in `app/dev/ui.tsx`.
