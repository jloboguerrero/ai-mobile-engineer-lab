# i18n — English + Spanish

- i18next + react-i18next + expo-localization. Keys typed (`resources` declared in
  `src/core/i18n/types.ts`) → a missing key is a TS error.
- Namespaces per feature: `features/x/i18n/en.json` + `es.json`, registered in `core/i18n/setup.ts`.
  Common words (`save`, `cancel`, errors by `ApiError.kind`) in `core/i18n/common.*.json`.
- **Both files in the same edit.** Adding a key to `en.json` without `es.json` is incomplete.
- `useTranslation('timeoff')` in screens/feature components. `src/ui` receives text as props.
- Language: device by default + manual selector in Me (persisted in MMKV).
- Server messages are English: map known ones to keys (`'No Employee records'` → `session.noRecords`);
  unknown ones shown as-is.
- Enums: value → translation key (`t(\`status.${status}\`)`); never send the label to the API.
- Interpolation, not concatenation: `t('hoursLeft', { count: 8 })` with plural keys.

## Dates & numbers

- `Intl` + `date-fns` with the active locale; currency USD (`Intl.NumberFormat(locale, { currency: 'USD', style: 'currency' })`).
- **Calendar dates** (time off days, dob, effectiveDate, pay date): keep as `'yyyy-MM-dd'` strings
  / `CalendarDate` type. No timezone conversion. Format with `parseISO` at local midnight.
- **Instants** (createdAt, signedAt): ISO → `Date` → shown in device timezone.
- API wire formats (`MM/dd/yyyy`) only inside `toRequest.ts` / mappers.
